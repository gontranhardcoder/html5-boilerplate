# HTML5 Boilerplate 🚀

Un **point de départ complet et commenté** pour tout projet HTML/CSS. Il intègre toutes les métadonnées SEO nécessaires (Open Graph, Twitter Card, JSON-LD, canonique…) pour que tu partes sur de bonnes bases.

## 📁 Structure du projet

```
html5-boilerplate/
├── index.html          ← le squelette HTML (très commenté)
├── css/
│   └── style.css       ← la feuille de style de base (commentée)
├── js/
│   └── main.js         ← le script JavaScript de base (commenté)
├── assets/
│   └── favicon.svg     ← l'icône du site (à personnaliser)
└── README.md
```

## 🚀 Démarrage rapide

1. **Télécharge / clone** le projet :
   ```bash
   git clone https://github.com/gontranhardcoder/html5-boilerplate.git
   ```
2. **Ouvre** `index.html` dans ton navigateur (double-clic).
3. **Personnalise** :
   - Le contenu dans `index.html`
   - Les couleurs/thème dans `css/style.css` (section « Variables CSS »)
   - Ton code dans `js/main.js`

## 🔍 SEO — ce qui est déjà inclus

Dans `index.html`, tu trouveras (tout est commenté) :

| Élément | Rôle |
|---|---|
| `<title>` + `meta description` | Titre et description affichés dans Google |
| `meta robots` | Contrôle de l'indexation |
| `link canonical` | Évite le contenu dupliqué |
| **Open Graph** (`og:*`) | Aperçu lors du partage Facebook / WhatsApp / LinkedIn |
| **Twitter Card** (`twitter:*`) | Aperçu lors du partage sur Twitter/X |
| `meta theme-color` | Couleur de la barre du navigateur mobile |
| **JSON-LD** (Schema.org) | Données structurées pour les moteurs de recherche |

> ⚠️ **Avant de publier** : remplace les URLs d'exemple (`https://www.monsite.com/`) et ajoute tes images de partage (`og-image.jpg`, 1200×630 px).

## 📝 À personnaliser

- **Langue** : change `lang="fr"` dans `<html>` si besoin.
- **Nom du site** : remplace « Mon Site » partout.
- **Favicon** : remplace `assets/favicon.svg` par ton logo.
- **Couleurs** : modifie les variables `--color-*` en haut de `css/style.css`.

## 🛠️ Technos

- HTML5 sémantique
- CSS moderne (variables, flexbox, responsive)
- JavaScript vanilla (aucune dépendance)
